# Design review rules

For UI work, use `.design-rules/SKILL.md` and its topic map at `.design-rules/references/hig-lookup.md`. Read the relevant guideline files under `.design-rules/references/hig/` before reviewing a design. The submodule pins the reviewed skill version.

Keep the practice runtime, Tab completion and device-local drafts functional. Never include private uploaded exam PDFs or school marking schemes in this public repository.

See DESIGN_REVIEW.md for the current design decisions and additional skills researched.
